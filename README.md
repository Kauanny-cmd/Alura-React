## ⚙️ Como Executar um Projeto

1. Escolha uma das pastas de projeto:
   ```bash
   cd projeto-01-introducao-react
  ````

2. Instale as dependências:
   ```bash
  npm install
  ````

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse no navegador:

   ```
   http://localhost:5173
   ```
